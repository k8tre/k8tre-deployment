# K8TRE Deployment Repo

This repository contains the manifests for deploying [K8TRE](https://github.com/k8tre/k8tre) at a host organisation. 

The deployment manifests expect that all _para-cluster_ infrastructure requirements have been met for your particular flavour of K8S. Please see [K8TRE docs](https://docs.k8tre.org/latest/) for more information or reach out to the K8TRE team for support.

This is in pre-alpha development phase. Please reports bugs or issues on the main K8TRE repo [here](https://github.com/k8tre/k8tre/issues).
